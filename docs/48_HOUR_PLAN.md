# AppRadar 48-Hour Execution Plan

## Day 1
1. Install Flutter.
2. Open `flutter_app`.
3. Run `flutter pub get`.
4. Run `flutter run -d chrome`.
5. Review Dashboard, Opportunities, App Details, Competitors, Reports and Build With AI.
6. Create Supabase project.
7. Run `supabase/schema.sql`.
8. Create GitHub repository and push this project.

## Day 2
1. Add GitHub Actions secrets.
2. Replace sample app data with a permitted app-data source.
3. Test `automation` locally.
4. Run GitHub Action manually.
5. Confirm the email arrives.
6. Enable the daily schedule.
7. Connect Flutter to Supabase.
8. Add screenshots/reviews/competitor intelligence in the next iteration.

## MVP success condition

Every morning, AppRadar should automatically:
Data -> Analyze -> Score -> Select Top Apps -> Generate Report -> Email.
